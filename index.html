About me

Senior Android Developer & indie maker

I'm a Senior Android Developer based in Minsk, Belarus. For more than nine years I've been building Android apps that handle real-world complexity — healthcare data, gaming platforms, real-time audio, ad SDKs — and my code runs in production for millions of users.

I started my career on the backend side, as an Oracle / PL/SQL developer designing databases and server-side logic. That background still shapes how I think about data, reliability and performance on mobile.

I've led Android teams, mentored developers, run code reviews and architecture discussions, and taken products from concept to Google Play release in Scrum and Kanban teams.

Outside of client work I run Vaunou Apps — my own small studio where I make games and apps end to end: idea, design, code, store listing and updates driven by what users tell me.
